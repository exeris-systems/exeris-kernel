# ADR-001 — Cloud Native & Agnostic Infrastructure Strategy (link stub)

**Authoritative copy:** `exeris-docs/adr/ADR-001 Cloud Native & Agnostic Infrastructure Strategy.md`

ADR-001 is a **platform-scope** decision owned by `exeris-docs`. It defines the CNCF baseline (Kubernetes, PostgreSQL, Redis, S3-compatible storage) that every Exeris repository inherits, including this one.

## Why this stub exists

The kernel was the original home of ADR-001 because cloud-agnosticism was first articulated as a kernel constraint. As the registry matured, platform-scope decisions were consolidated under `exeris-docs` so all Exeris repositories — kernel, sdk, spring-runtime, tooling, enterprise-observability — share a single source of truth.

## When to consult ADR-001

- Any infrastructure choice that touches deployment topology (K8s manifests, Helm charts, IaC).
- Any proposal to introduce a managed PaaS dependency (RDS, ElastiCache, Lambda) — ADR-001 forbids it.
- Any change to how the kernel discovers or binds to PostgreSQL / Redis / S3-compatible storage.
- Wall-integrity reviews where infrastructure assumptions are encoded in SPI or Core code.
